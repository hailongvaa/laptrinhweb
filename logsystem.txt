I. TỔNG QUAN TÁI CẤU TRÚC VÀ LÀM SẠCH HỆ THỐNG (SYSTEM RESTRUCTURING)

1. Mục tiêu tái cấu trúc:
   - Sắp xếp và quy hoạch lại toàn bộ cây thư mục dự án theo chuẩn chuyên nghiệp.
   - Giúp giảng viên, người chấm bài và các thành viên dễ theo dõi, dễ quan sát luồng 
     hoạt động và thẩm định mã nguồn mà không bị rối mắt bởi các thư mục trùng lặp.
   - Tích hợp toàn diện các tính năng của từng thành viên (Hân, Mai, Minh, Long) vào
     phiên bản chính thức chạy trên trình duyệt và máy chủ.
   - Bảo toàn 100% dữ liệu gốc của các bạn, đưa vào thư mục đóng gói lưu trữ chuẩn.

II. CHI TIẾT TÍCH HỢP ĐÓNG GÓP CỦA TỪNG THÀNH VIÊN
--------------------------------------------------------------------------------

1. BẠN HÂN (HÂN) - Chức năng Giỏ hàng, Đăng ký/Đăng nhập & Yêu thích:
   - File đóng góp gốc: /members_contributions/01_han_cart_and_auth/
   - Các tính năng đã tích hợp vào hệ sinh thái chính:
     * cart.html:
       + Thêm bộ nút tăng/giảm số lượng [+] và [-] trực quan cho từng sản phẩm.
       + Bổ sung logic JavaScript tính toán lại Tạm tính, Phí vận chuyển, Giảm giá và
         Tổng thanh toán ngay khi thay đổi số lượng hoặc xóa sản phẩm.
       + Hỗ trợ định dạng tiền tệ VNĐ chuẩn hóa (toLocaleString('vi-VN')).
     * register.html & login.html:
       + Bổ sung chức năng lưu thông tin đăng ký vào Web Storage (localStorage: 'registeredUser').
       + Kiểm tra mật khẩu xác nhận trùng khớp khi đăng ký.
       + Bổ sung logic kiểm tra thông tin đăng nhập từ localStorage ('currentUser') và 
         chuyển hướng người dùng về trang chủ (index.html).
     * wishlist.html:
       + Thêm hàm removeWishlist(button) cho phép xóa nhanh sản phẩm khỏi danh sách yêu thích
         và tự động cập nhật số lượng badge yêu thích hiển thị trên giao diện.

2. BẠN MAI (MAI) - Cơ sở dữ liệu quan hệ (RDBMS SQL Server) & Chuẩn hóa dữ liệu:
   - File đóng góp gốc: /members_contributions/02_mai_database_sql/
   - Các kịch bản và dữ liệu đã chuẩn hóa vào /database/:
     * Mô hình quan hệ chuẩn hóa 3NF gồm 4 bảng:
       + customers (Khách hàng): customer_id, full_name, email, phone, address, created_at.
       + products (Sản phẩm xe mô hình): product_id, name, brand, scale, price, stock, image_url.
       + orders (Đơn hàng): order_id, customer_id, order_date, total_amount, status, payment_method.
       + order_items (Chi tiết đơn hàng): item_id, order_id, product_id, quantity, unit_price.
     * Bộ dữ liệu mẫu phong phú: Đầy đủ các dòng siêu xe danh tiếng (Ferrari SF90, Porsche 911 GT3, 
       Rolls-Royce Phantom, Lamborghini Aventador...) với tỷ lệ thu nhỏ 1:18, 1:24, 1:64.
     * Ảnh sản phẩm Unsplash CDN chất lượng cao: Tích hợp trực tiếp vào DB và giao diện web.
     * Kịch bản báo cáo chuyên sâu: Câu lệnh truy vấn JOIN 4 bảng thống kê toàn bộ lịch sử mua hàng,
       tính tổng doanh thu và liệt kê chi tiết từng chiếc xe được đặt mua.

3. BẠN MINH (MINH) - Trải nghiệm điều hướng (Navigation), Phụ kiện & Luxury Header:
   - File đóng góp gốc: /members_contributions/03_minh_navigation_and_accessories/
   - Các hạng mục đã chuẩn hóa và lan tỏa trên toàn bộ 12 trang web:
     * Đồng bộ Navigation Bar trên TẤT CẢ 12 file HTML:
       Bổ sung mục menu 'Phụ kiện' (<a href="accessories.html">Phụ kiện</a>) giúp khách hàng
       dễ dàng truy cập trang phụ kiện mô hình từ bất kỳ trang nào.
     * Đồng bộ Footer trên TẤT CẢ 12 file HTML:
       Bổ sung liên kết đến 'Phụ kiện' (accessories.html) và 'Danh sách yêu thích' (wishlist.html)
       vào khối 'Liên kết nhanh' (Quick Links) ở chân trang.
     * Chuẩn hóa Header Luxury:
       Đồng bộ cấu trúc Header nền tối sang trọng, kèm biểu tượng tìm kiếm, giỏ hàng, tài khoản
       cho brands.html, brand-detail.html và accessories.html.

4. BẠN LONG (LONG) / KIẾN TRÚC HỆ THỐNG - Quản trị Admin, Backend API & Bảo mật:
   - Backend Node.js / Express (/car-store-backend/):
     * Cung cấp RESTful API đầy đủ: Xác thực (Auth JWT), Sản phẩm, Khách hàng, Đơn hàng, Thống kê.
     * Hỗ trợ lưu trữ dữ liệu dạng JSON File Database và kết nối SQL Server linh hoạt.
   - Module Quản trị nâng cao (/admin/):
     * Hệ thống Dashboard trực quan với biểu đồ doanh thu Chart.js.
     * Quản lý sản phẩm (CRUD): Thêm mới, chỉnh sửa, xóa mô hình xe.
     * Quản lý đơn hàng: Xem danh sách, cập nhật trạng thái đơn (Đang xử lý, Đang giao, Đã giao, Hủy).
     * Phân quyền quản trị (Role-Based Access Control - RBAC) và bảo vệ phiên làm việc qua admin-auth.js.

IV. HƯỚNG DẪN KHỞI CHẠY HỆ THỐNG (QUICK START GUIDE)
--------------------------------------------------------------------------------
1. Chạy giao diện Web (Frontend):
   - Cách 1: Sử dụng VS Code Extension "Live Server", mở thư mục dự án và nhấn "Go Live"
     tại trang `index.html`.
   - Cách 2: Mở trực tiếp file `index.html` bằng trình duyệt Chrome, Edge, Firefox.

2. Cài đặt Cơ sở dữ liệu (Database SQL Server):
   - Mở SQL Server Management Studio (SSMS).
   - Mở file `database/00_full_setup.sql` và nhấn `Execute (F5)`.
   - Toàn bộ cơ sở dữ liệu `CarStoreDB`, 4 bảng quan hệ, dữ liệu mẫu và báo cáo 
     sẽ được khởi tạo tự động trong 1 giây.

3. Chạy Máy chủ API (Backend Node.js - Tùy chọn nâng cao):
   - Mở Terminal/PowerShell tại thư mục `car-store-backend`:
     cd d:\laptrinhweb\car-store-backend
     npm install
     npm start
   - Máy chủ API sẽ lắng nghe tại: http://localhost:5000/

4. Truy cập Phân hệ Quản trị (Admin):
   - Mở trình duyệt và truy cập: `admin/index.html` hoặc đăng nhập qua `login.html`.
   - Tài khoản mẫu quản trị:
     * Email: admin@carstore.vn / Mật khẩu: admin123
